# Imágenes de Asignaturas para el Portal CIELO

Coloca en esta carpeta las imágenes reales de cada asignatura.

Las imágenes se integran visualmente sobre la superficie de cada carta y se muestran completas mediante **`object-fit: contain`**, conservando su proporción original sin deformaciones ni recortes.

---

## Nombres de archivo requeridos

| Asignatura | Nombre de archivo | Ruta pública |
|---|---|---|
| **Lengua Española** | `lengua-espanola.png` | `/portal/asignaturas/lengua-espanola.png` |
| **Matemática** | `matematicas.png` *(o `matematica.png`)* | `/portal/asignaturas/matematicas.png` |
| **Ciencias Sociales** | `ciencias-sociales.png` | `/portal/asignaturas/ciencias-sociales.png` |

| **Educación Física** | `educacion-fisica.png` | `/portal/asignaturas/educacion-fisica.png` |

> [!NOTE]
> Mientras una imagen no se encuentre en esta carpeta, la carta mostrará de forma segura un espacio reservado neutro y continuo con el fondo de la carta, sin errores ni imágenes rotas.
